"""

{
}

void setOffsets(inout vec2 particleOffset, inout vec2 barOffset, inout vec2 barSizeOffset, vec2 barAudio, vec2 particleAudio, float xCoordinate, float n, float lastN)
{  
}

void setProps()

}

void setParticleDownProps()
{
}

void modifySDFs()
{
}

#define enableGlow true
#define glowSize 1.0
#define glowIntensity .5
#define glowDirections 16.0
#define glowQuality 3.0
#define glowColor vec4(1)
#define glowBrightnessOffset .5
#define glowLightStrength 1
"""

coordinateRotation : The angle at which to rotate the Orthogonal Coordinates for the Fragment Shader Stage. You can use this to reverse the roles of the X and Y Axes, for instance, like so:
#define coordinateRotation 90

fragmentWidth : The width of the current "fragment" in pixels, in which the Primitives (Bar / Particle) will be drawn.
(INFO) A Primitives from a fragment in this context can not be overlapped with other fragments' Primitives.

visualiserDirections : The number of "sides" for the Primitives. 0 is only Up, 1 is only Down, 2 is both Up and Down.
visualiserMode : Decides the type of primitives to draw. 0 is Particles, 1 is Bars, 2 is both Particles and Bars.

enableGlow : Master Glow Switch. Use to enable or disable Glow Effect.
glowSize : Size of the Glow.
glowIntensity : Intensity with which to add in the neighboring colors.
glowDirections 16.0 : Number of directions to use while getting color data from radially-outward coordinates. Higher is Expensive.
glowQuality 3.0 : Quality of Glow. Higher is Expensive.
glowColor : Overlaying Color to use for the Glow Effect 
glowBrightnessOffset, glowLightStrength : Use to control the brightness and opacity of the final output Color.

(WARNING) Avoid directly using gl_FragCoord for querying coordinates. Instead use `bar.fragment.coords`, or `particle.fragment.coords`


Minimal working example:

"""
#include "linear/structs.glsl"

#define coordinateRotation 0
#define fragmentWidth 10

#define visualiserDirections 0
#define visualiserMode 2                            // Show both Particles and Bars

void init()
{
    // Set audio multiplier for Bars
    bar.audio.multiplier = 50;

    // Set audio multiplier for Particles
    particle.audio.multiplier = 50;
}


void audioFetch(inout float fetchedAudio, int n, int lastN)
{
}

void setOffsets(inout vec2 particleOffset, inout vec2 barOffset, inout vec2 barSizeOffset, vec2 barAudio, vec2 particleAudio, float xCoordinate, float n, float lastN)
{  
}

void setProps()
{
    //Set Bar Properties. Used only when visualiserMode is 1 or 2
    bar.size = vec3(12, 5, 0);
    bar.borderSize = vec3(2, 1, 2);

    bar.color = vec4(0, 0, 1, 1); 
    bar.borderColor = vec4(1);

    //Set Particle Properties. Used only when visualiserMode is 0 or 2
    particle.radius = 4;
    particle.borderSize = 2;

    particle.color = vec4(1, 0, 0, 1);
    particle.borderColor = vec4(1);
}

void setParticleDownProps()
{
}

void modifySDFs()
{
}

#define enableGlow false
#define glowSize 1.0
#define glowIntensity .5
#define glowDirections 16.0
#define glowQuality 3.0
#define glowColor vec4(1)
#define glowBrightnessOffset .5
#define glowLightStrength 1
"""

You can use the same config file for multiple desired outcomes. Override the #define attributes from the base `config.yaml` for each shader to control the outputs.

Example:
"""
- name: linear
        overrides:
          - visualiserMode=1
"""
Will only display bars, as visualiserMode has been set to 1 by the override.

(INFO)You can define your own attributes that can be overriden by the config file to further fine-tune the outcomes, while keeping the number of actual configuration files at a minimum!
