// 1. Particle size and number
numParticles	Higher is slower. Leave it as is to render maximum number of particles (screen.x*screen.y)
particleSize	Higher is slower. Radius of the individual particles. Minimum 1
windowScale	Determines the overall scale of the view, similar to how zoom works.

// 2. Particle Color, Opacity and Glow
color	Color of the particles 
opacity	Opacity of individual particles. Between 0 and 1
colorIntensityAddStrength	Uses Add Color Blend mode to mix colors when particles overlap. Between 0 and 1
antiAlias	Change this value in case some color combination produces jagged spherical edges. Greater than 0.

enableGlow	Master Glow Switch
glowSize	Determines the size of the glow.
glowIntensity	Determines the additive strength when adding glow to the visualiser
glowDirections	Higher is slower. The number of directions to look for while applying glow. The actual direction is then calculated by dividing 2*Pi by this number which specifies the angles around a point the glow shader looks at to apply the effect.
glowQuality	Higher is slower. The quality of the glow. If using lower glow intensity or lower glow size, then keeping it to a lower value would not produce much visual difference and thus would be recommended.
glowColor	The color to use to apply glow. Leave it to color to use the original color for glow, else specify as a vec3. For Example, vec3(0,1,0) would use a green color for glow
glowBrightnessOffset
glowLightStrength

// 3. Audio Influence
radiusAudioMultiplier	Determines the sphere's size change by the audio's lower frequencies
fractalAudioMixing	Between 40 and 1. Greater value means stronger reaction to beats or tonal changes in audio
fractalAudioMultiplier	Determines the strength by which the audio stream affects the inner Fractal Field displacements

// 4. Fractal Field Controls
octaveMultiplier	Defines the multiplier value with which a noise 'octave' gets added in to the final noise output. Higher values produce more peaks and valleys.
octaveScale	Defines the scale of each noise 'octave' that constitutes the final noise output.
complexity	Defines the number of octaves, or the number of values that add up in the final noise output. Higher is slower. 
fScale	Defines the scale of the overall noise-displaced particle grid. Higher value gives a 'zoomed-in' view, providing more displaced output.
gamma	Adjusts the difference between the valleys and peaks of the noise output, similar to gamma for brightness / contrast values.
minVal	Determines the minimum possible output value of the Noise function.
maxVal	Determines the minimum possible output value of the Noise function.

offset	Add offset to overall noise produced
noiseMultiplier	Multiplier for generated noise

// 5. Displacement and Flow Controls
isRadialDisplacement	If set to true, uses radial displacement mode. Strength is determined by displaceX.
displaceX	Determines Displacement Multiplier in X Axis
displaceY	Determines Displacement Multiplier in Y Axis
displaceZ	Determines Displacement Multiplier in Z Axis

flowX	Determines the Flow of the Fractal Field in X Axis
flowY	Determines the Flow of the Fractal Field in Y Axis
flowZ	Determines the Flow of the Fractal Field in Z Axis
flowEvolution	Determines the Flow Evolution of the Fractal Field in time

// 6. Sphere Controls
sphereRadius	The radius of the Sphere
feather	Between 0 and 1.  determines the size of the "band" around the Sphere
